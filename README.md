# FitBuddy — AI Fitness Plan Generator

FitBuddy is an AI-powered fitness planning web application.

## Technology Stack

- Python
- FastAPI
- Jinja2
- SQLite
- SQLAlchemy
- Google Gemini
- HTML
- CSS
- JavaScript

## Features

1. Personalized 7-day workout plan
2. AI nutrition/recovery tip
3. Feedback-based workout regeneration
4. SQLite database
5. Coach/Admin dashboard
6. Responsive UI
7. FastAPI Swagger documentation
